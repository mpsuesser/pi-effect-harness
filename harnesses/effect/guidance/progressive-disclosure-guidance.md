# Agent Rules

Load all relevant skills before writing or planning any code. Effect is a massive ecosystem — without loading skills you will write outdated v3 code or miss high-leverage libraries. Load AT LEAST 5 `effect-*` skills before any Effect work.

When skills leave any ambiguity, or when you encounter unfamiliar APIs during implementation, read from `~/.cache/effect-v4/` — the shared, user-scoped clone of the latest Effect v4 source. Key reference files:

- `~/.cache/effect-v4/LLMS.md` — Effect v4 overview for LLMs
- `~/.cache/effect-v4/MIGRATION.md` — v3 → v4 migration guide
- `~/.cache/effect-v4/packages/effect/SCHEMA.md` — full Schema documentation
- `~/.cache/effect-v4/packages/effect/HTTPAPI.md` — HttpApi, HttpApiClient, HttpApiBuilder
- `~/.cache/effect-v4/packages/effect/src/` — actual Effect source code for any module

Do not guess at Effect v4 APIs. If uncertain, read the reference first.
